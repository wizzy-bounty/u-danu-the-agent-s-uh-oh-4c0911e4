One word an agent says when it has no idea what to do: the satnav voice of a machine that lost the route and is recalculating. A single Python program (standard library only, no network) that writes that one word to `entry.txt`.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
